# yuleDKCS 数字钥匙连接系统

![yuleDKCS](https://img.shields.io/badge/version-2.0.0-blue.svg)

> **Yule Digital Key Connectivity Stack** — 完整的多协议数字钥匙全栈解决方案

---

## 🎯 项目概述

yuleDKCS 是一个全面的车辆数字钥匙系统，支持 **CCC**、**ICCOA**、**ICCE** 三大主流数字钥匙协议，提供从 **车辆嵌入式** → **云端服务** → **移动端 App** 的全栈技术实现。

| 组件 | 技术栈 | 状态 |
|------|--------|------|
| 🔧 **Backend** | Go + PostgreSQL + Redis + MQTT | ✅ 生产就绪 |
| 🎮 **Frontend** | React 18 + TypeScript + Material-UI | ✅ 生产就绪 |
| 📱 **Mobile SDK** | Swift (iOS) / Kotlin (Android) / Dart (Flutter) | ✅ 生产就绪 |
| 🚗 **Embedded** | C/C++ + FreeRTOS + SE050 | ✅ 生产就绪 |

## 🔑 核心功能

### 多协议支持
- **CCC R3** —  Car Connectivity Consortium 标准
- **ICCOA** — 智慧车联开放联盟标准
- **ICCE** — 移动终端金融科技委员会标准

### 钥匙全生命周期管理
- 发行 / 分享 / 撤销 / 过期
- 使用记录与审计日志
- 异常检测与风险评估

### 安全防护
- SE050 硬件安全元 (ECC P-256/384, AES-GCM, HMAC)
- SCP03 安全通道
- 证书链验证 (VehicleCA → Vehicle → DK)
- 安全启动 + 加密存储

### 精确车辆控制
- BLE 5.0 低功耗连接
- UWB 精确定位 (DS-TWR, 10cm 精度)
- 解锁/锁车 / 引擎启动 / 车窗控制
- 离线操作支持
