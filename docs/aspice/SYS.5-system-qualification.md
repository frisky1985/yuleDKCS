## 2. 三端集成测试计划

### 2.1 端到端场景测试（基于 spec-contract.md §3）

| 场景 ID | 场景 | 测试方法 | 预期通过条件 |
|:--------|:-----|:---------|:------------|
| S-01 | 车主首次创建数字钥匙 | BLE 配对流程 + 云端注册 | 全流程 ≤ 3min，钥匙状态 Active |
| S-02 | 日常无感解锁与上锁 | 靠近/离开场景模拟 | 解锁 ≤ 1s，离车 30s 后自动上锁 |
| S-03 | NFC 刷卡解锁 | 模拟手机断电 NFC 刷卡 | 解锁 ≤ 500ms，APDU 完整执行 |
| S-04 | 远程解锁 | App → Hub → DKCS → 车端 | E2E ≤ 3s，JWT + 签名双重认证 |
| S-05 | 发动机启动 | 车内 BLE + UWB 检测 | 启动授权 ≤ 500ms |
| S-06 | 钥匙分享与使用 | 主钥匙创建 → 分享 → 受邀者使用 | 分享创建 ≤ 30s，权限约束生效 |
| S-07 | 钥匙吊销 | 云端吊销 → 车端同步 | CRL TTL ≤ 10s，本地缓存生效 |
| S-08 | 中继攻击防护 | 信号放大/延迟注入 | 100% 被拒绝，安全告警记录 |
| S-09 | 多设备同时连接 | 8 台手机同时 BLE 连接 | 每台独立测距认证，正确识别 |
| S-10 | 双协议兼容 | ICCE 国密 / CCC 国际算法 | 自动识别协议，用户无感知 |
| S-11 | 安全启动失败 | 注入签名错误固件 | 启动终止，进入安全状态 |
| S-12 | 越权操作拒绝 | 临时钥匙尝试启动发动机 | 返回 403，记录越权尝试 |

### 2.2 集成测试数据流验证

| 测试 ID | 验证路径 | 输入 | 期望输出 |
|:--------|:---------|:-----|:---------|
| INT-01 | App → BLE → 车端 (解锁) | 手机靠近 ≤ 2m | CAN FD 解锁指令执行 |
| INT-02 | App → HTTPS → Hub → gRPC → DKCS → MQTT → 车端 (远程解锁) | 远程解锁请求 | 车端执行解锁 + 状态反馈 |
| INT-03 | 车端 → MQTT → DKCS → Kafka → Hub → App (钥匙状态推送) | 钥匙状态变更 | App 收到推送通知 |
| INT-04 | App → HTTPS → Hub → Java Adapter → 厂商 API (钥匙分享) | 分享请求 | 厂商 API 调用成功 |

## 3. 验收标准（基于 spec-contract.md §4 判定矩阵）
