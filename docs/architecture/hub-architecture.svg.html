CCC Digital Key 3.0 · ICCOA DK 3.0 · ICCE · Protocol Mapping

CCC Mailbox Protocol

  • • 6 × gRPC API: Create · Update · Delete · ReadDisplayFrom · ReadSecureFrom · Relinquish
  • • 传输层: CCC Adapter → MailboxController → Push (FCM/APNs)
  • • 零知识: Secret 在 URL fragment，server 不解密
  • • 轮询降级: 5s → 10s → 30s → 60s
  • • 状态机: 7 种状态 (含 PinReEntry)
  • • 测试: 31 单元 + 2 E2E

ICCOA S2S Protocol

  • • 架构: Hub ↔ 车服务器 ↔ 设备服务器 (无 Relay)
  • • 传输: 双向 TLS · REST/JSON · HTTP
  • • 车服务器 API (§13.5): 14 个端点
  • • 设备服务器 API (§13.6): 4 个端点
  • • 分享流程: 16 步 (CA模式) / 24 步 (手机账号)
  • • 错误码: 40000~50001 共 14 个
  • • S2S 客户端: 12 API 已实现 + 34 mock 测试

ICCE Protocol

  • • 架构: 与 ICCOA 相同 (车服务器中心)
  • • 华为主导，中国车企生态
  • • 支持国密 SM2/SM3/SM4
  • • 边缘计算 + UWB FiRa
  • • S2S 客户端基础框架就绪
  • • 需 ICCE 规范 PDF 完善类型定义
  • • 当前: stub 模式，等待对接
