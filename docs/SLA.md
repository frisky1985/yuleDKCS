# 📋 yuleDKCS 服务等级协议 (SLA)

> **文档版本**: v1.0 | **生效日期**: 2026-07-30
> **适用服务**: yuleDKCS 云端服务 (Hub + DKCS + Adapters)

---

## 1. 服务范围

本 SLA 覆盖 yuleDKCS 云端服务平台的全部公开 API 端点：

| 服务 | 端点类型 | 协议 | 说明 |
|:-----|:--------:|:----:|:-----|
| Hub Gateway | REST + gRPC | HTTPS/gRPC-TLS | API 网关、JWT 鉴权、协议路由 |
| DKCS | gRPC | gRPC-TLS | 密钥生命周期、Token 管理、权限校验 |
| Adapters | gRPC | gRPC-TLS | TSP 适配器（CCC/ICCOA/ICCE） |

**不适用场景：**
- 嵌入式车端固件（独立 SLO 待定）
- 第三方 TSP 系统可用性
- 客户端网络及设备端问题

---

## 2. 服务等级目标 (SLO)

### 2.1 核心指标

| 指标 | 目标 | 测量方式 | 测量窗口 |
|:-----|:----:|:---------|:--------:|
| **可用性 (Uptime)** | ≥ **99.9%** | SLI: 请求成功率 | 月度 |
| **P99 延迟** | ≤ **500ms** | SLI: 端到端请求延迟 | 分钟级采样 |
| **P95 延迟** | ≤ **200ms** | SLI: 端到端请求延迟 | 分钟级采样 |
| **错误率** | < **0.1%** | SLI: HTTP 5xx / gRPC Internal | 分钟级采样 |
| **吞吐量** | ≥ **1,000 QPS** | 每节点（可水平扩展） | 实时 |

### 2.2 可用性计算

```
月度可用性 = (总分钟数 - 不可用分钟数) / 总分钟数 × 100%

其中"不可用"定义为：连续 5 分钟内错误率 > 5%
```

### 2.3 例外情况

以下不计入不可用时间：
- 计划的维护窗口（每月 ≤ 2 次，每次 ≤ 30 分钟，提前 7 天通知）
- 第三方依赖故障（云服务商、CDN、DNS）
- 客户侧造成的故障（错误配置、超配额调用）
- DDoS 攻击等不可抗力

## 3. 服务等级指标 (SLI)

### 3.1 请求成功率

```
SLI = 成功响应数 / 总请求数 × 100%
```

- 成功响应：HTTP 2xx / gRPC OK
- 采集点：Hub 网关层
- 采集频率：每分钟聚合

### 3.2 延迟

```
SLI = P99/P95 百分位延迟（ms）
```

- 测量点：从 Hub 接收请求到完成处理并返回
- 不包括客户端网络延迟
- 采样：每 10 秒采样窗口

### 3.3 错误率

```
SLI = 5xx/Internal 响应数 / 总请求数 × 100%
```

## 4. 告警阈值

| 级别 | 触发条件 | 响应时间 | 通知方式 |
|:----|:---------|:--------:|:---------|
| 🔴 **P0 Critical** | 可用性 < 99.5% 或 错误率 > 5% | ≤ 5 min | 电话 + 飞书 @all |
| 🟠 **P1 High** | P99 > 1s 或 错误率 > 1% | ≤ 15 min | 飞书群 @oncall |
| 🟡 **P2 Medium** | P99 > 500ms 或 错误率 > 0.5% | ≤ 30 min | 飞书群通知 |
| 🔵 **P3 Low** | 单节点异常 / 慢查询 | ≤ 2h | 飞书通知 |

---

## 5. 运维响应等级

| 等级 | 定义 | 响应时间 | 故障修复时间 (MTTR) |
|:----|:-----|:--------:|:------------------:|
| **P0** | 服务完全不可用，影响全部用户 | 立即响应 | ≤ 30 min |
| **P1** | 核心功能降级，影响部分用户 | ≤ 15 min | ≤ 2h |
| **P2** | 非核心功能异常，不影响主流程 | ≤ 30 min | ≤ 8h |
| **P3** | 运维优化/技术债务 | ≤ 2h | 下一个迭代 |

## 6. 变更管理

| 变更类型 | 审批 | 通知 | 窗口 |
|:---------|:----:|:----|:-----|
| 常规发布 | Code Review + CI 全绿 | 飞书发布群通知 | 工作日 10:00-16:00 |
| 紧急修复 | Owner 授权 + 事后补审 | P0 即时 + 群公告 | 随时，需回滚方案 |
| 架构变更 | 架构评审会 | 提前 2 周 | 规划窗口 |
| 基础设施变更 | 运维审批 | 提前 1 周 | 维护窗口 |

## 7. 备份与恢复

| 组件 | 备份策略 | RPO | RTO |
|:-----|:---------|:---:|:---:|
| PostgreSQL | 每日全量 + WAL 持续归档 | ≤ 1h | ≤ 30 min |
| Redis | RDB 每 5 分钟 + AOF | ≤ 5 min | ≤ 5 min |
| 配置 | GitOps (Git 历史) | 即时 | ≤ 15 min |
| 证书/密钥 | HSM + KMS 双活 | 0 (HSM 同步) | 即时 |

## 8. 服务积分

| 月度可用性 | 服务积分 |
|:-----------|:--------:|
| ≥ 99.9% | 无 |
| 99.0% ~ 99.9% | 10% |
| 95.0% ~ 99.0% | 25% |
| < 95.0% | 50% |

服务积分以月度账单抵扣形式发放，最高不超过当月服务费的 50%。

## 9. 附录：可观测性

### Prometheus 指标

| 指标名 | 类型 | 说明 |
|:-------|:----:|:-----|
| `yule_dkcs_requests_total` | Counter | 请求总数（按 method/status 分） |
| `yule_dkcs_request_duration_ms` | Histogram | 请求延迟分布 |
| `yule_dkcs_errors_total` | Counter | 错误计数（按 code 分） |
| `yule_dkcs_up` | Gauge | 服务存活（0/1） |
| `yule_dkcs_in_flight_requests` | Gauge | 当前处理中请求数 |

### Grafana Dashboard

预置 Dashboard ID: `yule-dkcs-production`，包含：
- 实时 QPS / 延迟 / 错误率面板
- SLA 达标率月度视图
- 各服务健康状态
- 资源利用率 (CPU/Mem/Conn)
